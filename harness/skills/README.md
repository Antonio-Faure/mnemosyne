# Harness interaction skills

Vendored from **browser-use/browser-harness** (`interaction-skills/`, MIT) so the
browser agent can read them offline. They explain how to handle tricky web
interactions (tabs, dropdowns, dialogs, scrolling, iframes, screenshots…).

Only the subset relevant to mnemosyne is kept. Source:
https://github.com/browser-use/browser-harness/tree/main/interaction-skills
